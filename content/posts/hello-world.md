# Hello, World :D !

This is the first post on the new static site generator. It's built with:

- **Go** - the SSG binary that compiles markdown into HTML
- **Goldmark** - for markdown parsing
- **HTMX** - for the CMS admin panel
- **Tailwind CSS** - for styling
- **GitHub Pages** - for hosting

## How it works

1. Open the admin panel at `/admin` and write a post in the browser
2. Click **Save** - post is saved and site auto-builds
3. Use **Build** to manually rebuild, or **Publish** to commit and push to GitHub
4. Push to GitHub - Actions deploys automatically
