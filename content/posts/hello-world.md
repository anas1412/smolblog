# Hello, World :D !

This is the first post on the new static site generator. It's built with:

- **Go** — the SSG binary that compiles markdown into HTML
- **Goldmark** — for markdown parsing
- **HTMX** — for the CMS admin panel
- **Tailwind CSS** — for styling
- **GitHub Pages** — for hosting

## How it works

1. Write posts in `content/posts/` with YAML frontmatter
2. Run `./smolblog build` to generate the static site in `dist/`
3. Push to GitHub — Actions deploys automatically
