# Why HTMX and Tailwind Are a Great Pair

HTMX and Tailwind CSS complement each other perfectly for building interactive sites without writing JavaScript.

## HTMX

HTMX lets you build dynamic interfaces using only HTML attributes:

```html
<button hx-post="/click" hx-target="#result">
    Click Me
</button>
```

## Tailwind

Tailwind provides utility-first CSS that keeps your HTML clean and your bundle small.

## Together

No build step for JS. No React. No Vue. Just HTML attributes and utility classes. It's liberating.
