Smolblog is a lightweight static site generator built with Go. It uses Markdown for content, HTMX for the admin UI, and generates flat HTML that you can deploy anywhere — no database, no server runtime.

### Why Smolblog?

- **Simple** — write in Markdown, get static HTML
- **Fast** — compiled Go, sub-second builds
- **Self-contained** — one binary, no dependencies
- **Fun** — built to learn and to share
